# Format: local-name|url  ->  fetch.sh writes reference/raw/<local-name>.css
# All are served without authentication. URLs carry content hashes, so they
# change on every ODC release — recapture with, in the browser console:
#   [...document.styleSheets].map(s => s.href).filter(Boolean).join('\n')
#
# WHAT IS ACTUALLY MINED, as opposed to kept for reference:
#   neo-design-system.original   tools/build.py splits this into src/**
#   unified-shell                tools/build.py splits this into src/04-shell/
#   old-neo-design-system        THREE extractors take whitelisted subsets:
#                                extract_legacy_layout.py  (.ds-layout, .main)
#                                extract_legacy_widgets.py (ds-avatar, table)
#                                osui_reskin.py            (the OSUI overrides)
#                                Anything outside those whitelists is NOT in
#                                the bundle even though the file is captured.
#                                That is how `html.is-soft-responsive` and
#                                `--min-supported-width` were missed until
#                                2026-09-07 — see section 15 of
#                                compat/neo-odc-compat.css.
#   outsystems-ui-theme          read by audit_osui_theme.py / collisions.py
#   everything else              reference only, never emitted
#

#                                         --horizontal and --collapsed variants.

# invisible to it; it matters only for apps that do.
